问题1：点下载，浏览器直接打开源码文本，不弹出保存文件？
解决方法：
1. 鼠标放到下载按钮上面，不要点击；
2. 鼠标右键，选择【另存为】；
3. 保存类型选【所有文件】，文件名结尾写上 .bat；
4. 编码保持默认，保存到桌面即可。
问题2：双击bat脚本，黑框一闪直接消失，打不开？
解决方法：
1. 找到下载好的bat文件；
2. 鼠标右键这个文件；
3. 点【以管理员身份运行】；
4. 不要直接双击，权限不够就会闪退。
问题3：杀毒软件/Windows Defender直接把脚本删掉？
解决方法：
1. Windows安全中心 → 病毒和威胁防护；
2. 找到【保护历史记录】，把被隔离的bat文件恢复；
3. 添加排除项，把存放脚本的文件夹加入白名单；
注意：脚本修改系统设置，会被杀毒误报，确认来源再放行。
问题4：打开bat脚本里面中文全部乱码？
解决方法：
1. 不要用WPS记事本保存bat；
2. 使用系统自带记事本打开脚本；
3. 文件 → 另存为，编码选择【UTF-8】，覆盖保存。
问题5：下载完，看不到 .bat后缀，只有文件名？
解决方法：
1. 打开此电脑，顶部点【查看】；
2. 勾选【文件扩展名】；
3. 现在就能看到 .bat后缀，修改文件名不会把后缀弄丢。
