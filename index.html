问题1：本地打开网页下载失效？ Q1: Download does not work when open local file?
本下载功能依赖GitHub Pages线上环境，本地双击HTML会触发浏览器跨域限制，必须访问部署后的网页链接才能一键下载。 Download requires GitHub Pages online environment. Local HTML file triggers browser CORS restriction, use deployed website link for one‑click download.
问题2：双击bat脚本黑框一闪消失？ Q2: Bat script flashes and closes immediately?
右键脚本，选择【以管理员身份运行】，不要直接双击打开。 Right‑click script → Run as administrator, do not double‑click directly.
问题3：杀毒软件删除脚本？ Q3: Antivirus deletes script?
脚本修改系统权限，会产生误报，在Windows安全中心恢复文件并添加文件夹白名单。 Scripts modify system permissions, causing false positives. Restore file in Windows Security and add folder to whitelist.
