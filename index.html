❓ 常见问题FAQ

问题1：本地打开网页下载失效？ Q1: Download does not work when opening locally?
本下载功能依赖GitHub Pages线上环境，本地双击HTML会触发浏览器跨域限制，必须访问部署后的网页链接才能一键下载。 Download requires GitHub Pages online environment. Local HTML file triggers browser CORS restriction. Use the deployed website link for one-click download.
问题2：双击bat脚本黑框一闪消失？ Q2: Bat script flashes and closes immediately?
右键脚本，选择【以管理员身份运行】，不要直接双击打开。 Right-click the script, select Run as administrator. Do not double-click directly.
问题3：杀毒软件删除脚本？ Q3: Antivirus deletes the script?
脚本修改系统权限，会产生误报，在Windows安全中心恢复文件并添加文件夹白名单。 Scripts modify system permissions and may trigger false positives. Restore the file in Windows Security and add the folder to the whitelist.
问题4：脚本需要什么Windows系统支持？ Q4: Which Windows systems are supported?
本项目主要面向 Windows10 20H2以上版本、Windows11。部分简单批处理脚本可以在Win7运行，但PowerShell相关工具会出现功能缺失，Win7不做优先兼容。建议使用新版Windows获得全部脚本能力。 This project mainly supports Windows 10 20H2 and above, and Windows 11. Some simple batch scripts may work on Win7, but PowerShell-related tools may be missing features. Win7 compatibility is not prioritized.
问题5：解压zip压缩包的时候报错怎么办？ Q5: What should I do if the ZIP extraction reports an error?
第一确保存放路径文件夹名称不要出现中文、特殊符号、空格；第二不要直接在压缩软件预览窗口双击脚本；第三可以临时关闭杀毒软件实时防护再解压；优先使用Windows系统自带解压功能。 Make sure the extraction path does not contain Chinese characters, special symbols or spaces. Do not run the script directly from the archive preview window. You may temporarily disable antivirus real-time protection and use Windows built-in extraction.
问题6：运行脚本提示权限不足，功能执行失败？ Q6: The script reports insufficient permissions?
绝大多数系统修改类脚本必须右键，选择以管理员身份运行。普通用户权限下读写系统目录、修改注册表的操作会直接拒绝执行，导致脚本半截卡住或者没有效果。 Most system modification scripts must be right-clicked and run as administrator. Under normal user permissions, writing to system folders and modifying the registry may be denied.
问题7：GitHub Pages网页访问很慢、加载卡顿？ Q7: GitHub Pages is slow to load?
GitHub服务器在海外，国内网络环境下访问会存在延迟，页面打开慢、图片加载失败属于正常现象。可以直接下载源码到本地查看文档，或者使用镜像站点访问项目。 GitHub servers are located overseas, so access may be slower in some regions. You can download the source code locally or use a mirror site.
问题8：我可以修改脚本，拿来自己二次分发吗？ Q8: Can I modify and redistribute the scripts?
本项目采用MIT开源协议。你可以修改源代码，但是分发的时候需要保留原始开源协议与原作者版权声明，不能抹除来源，禁止把本脚本闭源拿去做商业售卖。 This project uses the MIT License. You may modify the source code, but you must keep the original license and copyright notice. Do not remove the author information or sell these scripts as closed-source commercial software.
问题9：脚本运行一闪而过，黑窗口直接关闭？ Q9: The script window closes immediately?
两种常见情况：①没有管理员权限直接双击；②脚本执行完毕没有pause暂停命令，执行完成自动退出。解决方法：打开cmd手动cd到脚本文件夹，控制台内输入脚本文件名运行，可以看到完整报错信息。 Two common reasons: ① you did not run as administrator; ② the script finished without a pause command. Open CMD, cd to the script folder, and run the script manually to see the full error message.
问题10：下载之后，文件夹里面很多bat ps1文件，我该运行哪一个？ Q10: Which script should I run after downloading?
每个脚本文件名代表对应的功能，阅读脚本目录内README说明文档，查看每个脚本用途。不要随意运行文件名看不懂的脚本，确认功能之后再执行。 Each script filename indicates its purpose. Read the README file in the script folder. Do not run unknown scripts without confirming their function.
问题11：脚本执行完之后，系统出异常怎么恢复？ Q11: How do I restore the system after a script error?
部分修改系统设置脚本会提供回滚脚本。如果没有回滚脚本，优先使用Windows系统还原点恢复系统状态；如果你没有创建还原点，则需要手动修改对应注册表或者系统选项恢复。 Some system-setting scripts may provide a rollback script. If not, use a Windows system restore point. If you do not have a restore point, you may need to manually modify the corresponding registry or system settings.
问题12：为什么不做成exe程序，直接双击使用？ Q12: Why not make it an EXE file?
转换成exe会带来两个问题：第一，编译之后的exe无法直接阅读源码，用户无法检查代码安全性；第二exe文件会更加容易被杀毒软件判定为恶意程序。保留原始bat、ps1可以让所有人直接审阅全部脚本代码。 Compiling to EXE makes the source code harder to audit and more likely to be flagged by antivirus software. Keeping the original bat and ps1 files allows everyone to review the full script code.
