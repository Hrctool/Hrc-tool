# HRC 系统优化工具集

> 纯本地运行的 Windows 系统优化一站式解决方案，无广告、无遥测、无后台常驻。

## 项目简介

HRC 系统优化工具是一款基于 PowerShell + WinForms 开发的 Windows 系统修复与优化工具，
覆盖 Win7 到 Win11 全版本。所有操作均在本地执行，不收集任何用户信息。

### 核心特性

- 🔧 **21 步全链路修复**：Winsock 重置、DISM/SFC 扫描、运行库补全、驱动环境部署
- 🎨 **可视化操作界面**：粒子动画启动屏 + 进度条，告别黑窗口
- 🛡️ **安全软件管理**：一键卸载全家桶，静默安装火绒
- ⚡ **性能拉满**：高性能电源计划、显示器刷新率自动拉满、Defender 扫描限流 5%
- 🔁 **重启续跑**：支持设置重启后自动执行全量修复（RunOnce 模式）
- 🎵 **开机音效**：自动扫描外接设备音乐文件，启动时播放
- 📦 **智能下载**：官方源 + 清华镜像 + ghproxy 多重 fallback，下载失败自动重试

### 内置运行模式（12 种）

| 模式 | 说明 |
|------|------|
| 全自动基础模式 | 无弹窗自动执行，兼容所有设备 |
| 全家桶全清 + 火绒安装 | 除火绒外所有安全软件全部卸载 |
| Win7–Win11 全系统清理修复 | 全版本兼容清理 |
| 手动确认模式 | 每步优化前弹窗确认，可跳过 |
| 强打驱动模式 | 老设备官方驱动强制安装 |
| 轻量兼容模式 | 仅基础优化，保留系统原生功能 |
| 联网全量扫描修复 | 21 步全链路修复 + 重启内存检测 |
| 离线全量扫描修复 | 仅本地命令，不联网 |
| 希沃一体机专用版 | 保留希沃全部自带功能 |
| 常用软件自动安装 | 静默安装常用工具 |
| 系统激活/版本切换 | 调用 MAS 开源方案一键激活 |
| 本地账户密码重置 | 清空管理员/来宾账户密码 |

## 使用方法

1. 右键 `(最推荐)优化脚本无bug3.0版.bat` → **以管理员身份运行**
2. 阅读并同意隐私声明
3. 选择需要的运行模式
4. 等待执行完成，按提示重启

> ⚠️ **重要提醒**
> - 执行前请保存所有工作，工具完成后会提示重启
> - 部分模式会卸载第三方安全软件，请确保你了解后果
> - 密码重置模式仅限合法授权的设备使用

## 技术架构

- **前端**：PowerShell WinForms（无外部依赖）
- **后端**：原生 Windows 命令（netsh / dism / sfc / bcdedit）
- **下载组件**：VC++ 运行库、JDK 17、火绒安全、TranslucentTB
- **运行环境**：Windows 7 SP1+ / PowerShell 5.1+
